# Contribuir

Explique o problema e o comportamento esperado em uma issue. Use dados fictícios
para reproduzir problemas de rede e não inclua credenciais ou inventários reais.

Antes de enviar uma alteração, execute `npm run build` e `cargo test` na pasta
`src-tauri`. Use `npm run tauri:build -- --no-sign` para builds locais sem acesso
à identidade de assinatura. Atualize o README se alterar instalação, dados
coletados ou funcionalidades.
